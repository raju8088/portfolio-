How It Works

The full
workflow

Two separate n8n workflows handle the complete call lifecycle — from triggering outbound calls to receiving VAPI webhooks and updating the CRM.

⏰

Schedule Trigger — 9 AM daily

n8n fires Mon–Sat at 9 AM. For demo: manual trigger used to run live.

📋

Fetch customer list

Google Sheets node reads all customers — Name, Phone, Plot, Stage, LastCallSummary (memory).

🔁

Loop each customer

Split in Batches processes one customer at a time. Waits 3 seconds between calls to avoid rate limits.

🧠

Build personalised script

Code node generates a unique system prompt per customer — injects name, plot, construction stage, and last call memory.

📞

VAPI initiates call

HTTP POST to api.vapi.ai/call/phone with assistant config + customer phone. VAPI dials using Twilio.

⏳

Poll until call ends

GET /call/{id} every 15 seconds. When status = ended, fetch transcript + VAPI summary.

🤖

GPT-4o-mini analysis

Analyses transcript for sentiment, visit intent, follow-up flags, and generates a 2-line call summary.

💾

Log + update memory

Writes full results to Sheet2 (Call Log) and updates LastCallSummary in Sheet1 for the next call.
